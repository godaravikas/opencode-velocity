# Changelog

## [0.1.0] - First release



### Main Features

- **OpenCode TUI Report:** Open `/velocity` in the OpenCode TUI for an interactive report. When you exit, you’ll return to the same session.
- **Multiple output formats:** View formatted terminal output or download detailed HTML report.
- **Cross-project analytics:** Review project and session counts, user turns, messages, tokens, costs, and effort in one report.
- **Session hierarchy:** Group parent sessions with their subagent sessions and display child sessions beneath their parent.
- **Usage breakdowns:** Analyze provider/model usage and best-effort tool-call totals.
- **Effort tracking:** Review active effort and per-session duration alongside usage and cost.
- **Configurable credit conversion:** Set the dollar value of one credit in the TUI.
